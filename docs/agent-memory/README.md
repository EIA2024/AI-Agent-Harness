## 命名与维护约定

- 文件名：`NNN-短横线主题.md`，编号递增，不重复。
- 每条记录开头写：主题、日期、相关分支/提交范围。
- 记录是**过程事实**（发生了什么、为什么、当前状态），不是工作区规则；跨模块的硬性约束见仓库根 `CLAUDE.md`。
- 过时的记录不要删除，标记 `[SUPERSEDED]` 并指向替代记录；错误的事实就地更正。
